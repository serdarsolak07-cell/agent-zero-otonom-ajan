3. **03-uyku** — Gece bakımı
4. **04-guvenlik-saglik** — Güvenlik, sağlık kontrolü, sürümleme
5. **05-kaynak-baglam** — Kaynak Kontrolü + bağlam sıfırlama
6. **06-acil-durdurma** — Model dışı bekçi süreci
7. **07-web-ayarlar** — Web UI Ayarlar
8. **08-sesli** — Sesli katman
